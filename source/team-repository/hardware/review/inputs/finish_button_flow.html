A

Two independent circuits in one button

The switch contacts and lamp terminals are separate. There is no wire from FINISH_SW to the buffer input.

Circuit Connection Meaning
Press input SW25 → FINISH_SW → MCP23S17 GPA5, pin 26 LOW means you pressed the button.
Lamp control MCP23S17 GPB0, pin 1 → FINISH_LED_3V3 → 74ACT244 pin 8 HIGH requests lamp illumination.
Gate drive 74ACT244 pin 12 → FINISH_GATE_5V → R27 → Q10 Gate A HIGH Gate turns Q10 on.
B

At 30 seconds, software turns the lamp on

Initially, software configures GPA5 as input and GPB0 as output LOW. The buffer and Gate are LOW; the lamp is off.

The drawn lamp-current path is +5V_LOAD → R29 → D10 → Q10 Drain → Q10 Source → GND. GPB0 supplies a control signal. The load supply provides the lamp current. The expander holds GPB0 HIGH between SPI transactions.

C

Pressing SW25 reports an input

  1. Press SW25: its contacts connect FINISH_SW to GND.
  2. GPA5 becomes about 0 V. GPB0 keeps its previous output state.
  3. PIC polls GPIOA through SPI2. The returned byte has bit 5 cleared.
  4. Software debounces the input and creates FINISH_PRESSED.
  5. In Finishable, the game enters GameOver. It stops the game and starts the result and treat sequence.

The switch-current path is 3.3 V → R25, 10 kΩ → SW25 → GND. Current is about 0.33 mA.

Before 30 s, the same press still changes GPA5, but game software ignores FINISH_PRESSED. Releasing the momentary switch opens its contacts. R25 returns GPA5 HIGH; this does not restart the game.

To extinguish the lamp, PIC must separately command GPB0 LOW. Pressing SW25 alone cannot extinguish it. The exact lamp-off timing during GameOver is not yet specified in the state-machine document.

D

Why R28 does not conflict

R28 is a 100 kΩ pull-down on the MOSFET Gate. It is not a direct short to GND. With a nominal 5 V buffer output, R27 and R28 form a 1 kΩ / 100 kΩ divider.

The steady Gate voltage is about 5 × 100 / 101 = 4.95 V. The pull-down current is about 50 µA. When the buffer drives LOW, R28 also pulls LOW. Both keep the MOSFET off.

R36 is a separate 10 kΩ pull-down at the buffer input. It holds that input LOW while GPB0 is undriven.

Which PIC pins send and receive the commands?

SPI2 signal Physical connection
SS PIC pin 17 → MCP pin 11
SCK PIC pin 26 → MCP pin 12
MOSI: commands PIC pin 22 → MCP pin 13, SI
MISO: input readings MCP pin 14, SO → PIC pin 24

Each transaction holds SS LOW while the bytes transfer. PIC raises SS after the transfer finishes. These example bytes assume BANK = 0, address bits 000, normal input polarity, and GPB0 already configured as output.

Action Bytes sent on MOSI Result
Lamp on 0x40, 0x15, 0x01 Write OLATB; set GPB0 HIGH. Only GPB0 controls a load here.
Read switches 0x41, 0x12, 0x00 Read GPIOA on MISO during the last byte. Test bit 5 for Finish.
Lamp off 0x40, 0x15, 0x00 Write OLATB; set GPB0 LOW.

The final read byte is a dummy byte that supplies clocks. It does not write zero into the input register. Register addresses and SPI framing: Microchip MCP23S17 datasheet.

Current implementation status

This explains the intended hardware and firmware behavior. The firmware is still a scaffold; these SPI transactions are not implemented.

The schematic currently uses a provisional +5 V lamp supply. Confirm the actual button lamp voltage, current, and R29 before wiring.

A selected 12 V lamp would need its rated lamp supply; the expander remains at 3.3 V and the buffer at 5 V.
